# Ariq Anwar V4
Upload all files to the root of your GitHub repository.

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

## Voice
Use Chrome Android over HTTPS (GitHub Pages). Press the microphone and allow microphone permission.

## App launching
V3 tries Android intent links for YouTube, Minecraft, TikTok and Blockman GO. If the app cannot be opened, it falls back to the web/store page. Exact behavior depends on Android, Chrome and whether the app is installed.

## Home screen
After GitHub Pages is live, Chrome may show **＋ Pasang**. You can also use Chrome ⋮ → Add to Home screen / Install app.
